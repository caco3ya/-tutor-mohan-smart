# 🐦 tutor Mohan - Smart PPT Generator

Welcome to the official **tutor Mohan Smart PPT Generator** repository (`tutor-mohan-smart`). This is a completely serverless, client-side web application designed to instantly turn raw educational PDFs into branded, interactive presentation slides.

## ✨ Features
* **Drag-and-Drop Parsing:** Extracts raw text directly out of PDF files locally within your web browser.
* **AI Concept Analysis:** Connects securely to OpenAI (GPT-4o-mini) or Google Gemini (1.5-Flash) to structure your lesson content.
* **Interactive Disappearing Layouts:** Automatically packages concepts into **Question & Hidden Answer** format using Reveal.js fragments.
* **Custom Identity Branding:** Hardcoded to support the official **tutor Mohan** brand typography (Fredoka Font), Navy Blue (`#0A2540`), and Orange (`#FF6B35`) accent themes.

## 🚀 How to Use the Live App
1. Open the live link generated by your GitHub Pages deployment.
2. Select your AI provider (OpenAI or Gemini) and enter your temporary API Key (processed safely inside your browser session only).
3. Drag and drop any document PDF script directly into the drop zone.
4. Click **Build tutor Mohan Presentation** to download a standalone `.html` presentation deck file.
